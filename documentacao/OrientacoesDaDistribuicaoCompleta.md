# Orientações da distribuição completa

Esta distribuição foi preparada para consulta, estudo, manutenção e publicação
no GitHub Pages. Use um servidor local para abrir `index.html` e
`paginas/AdministracaoDoObservatorio.html`. Scripts, testes, documentação e resultados
processados ficam na raiz. Os microdados individuais não acompanham o pacote;
a área de Administração os lê localmente, sem incorporá-los ao ZIP público.
